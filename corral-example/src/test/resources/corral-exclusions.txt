# Rules this codebase permanently opts out of, because they do not apply here.
#
#   <rule-id> :: <reason>
#
# An id that matches no rule in the run logs a warning rather than quietly excluding nothing — a
# typo or a renamed rule. A reason is mandatory: Corral cannot judge whether it is a good one, but
# it can make its absence fatal. Every exclusion in effect is printed on any rule failure.
#
# This is NOT a pause button. An excluded rule records nothing, so any violation added while it is
# off resurfaces as new the day the line is deleted. See docs/excluding-a-rule.md.

corral.logging.no-system-err :: Demonstrating exclusion is this module's job; StderrWriterAllowedByExclusion is the demo.
